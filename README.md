# MangaDex RU Reader (MVP)

Минималистичный, быстрый и удобный ридер манги, манхвы и маньхуа на русском языке на базе открытого API [MangaDex](https://api.mangadex.org/). Проект вдохновлен концепцией и удобством ReadManga ([a.zazaza.me](https://a.zazaza.me/)).

## Особенности
- **Только русский язык:** фильтрация на уровне API (`availableTranslatedLanguage[]=ru`). Доступно свыше 5 800 тайтлов и 102 000 глав на русском языке.
- **Стек технологий:** Vue 3 (Composition API), Nuxt 3 (режим SPA), Pinia, Tailwind CSS, Lucide Icons.
- **Функционал читалки:**
  - Два режима чтения: вертикальная непрерывная **лента (webtoon)** и **постраничный** режим с навигацией стрелками клавиатуры.
  - Переключение качества страниц (оригинал / сжатие для экономии трафика).
  - Настройка ширины контейнера.
  - Быстрое переключение глав и выпадающий список всех глав.
- **Закладки и история «Вы читали»:**
  - Локальное сохранение в `Pinia` + `localStorage` без необходимости регистрации.
  - Статусы закладок: *Читаю, В планах, Прочитано, Любимое, Брошено*.
  - Автоматическое запоминание последней прочитанной главы.
- **Каталог и поиск:**
  - Живой поиск с задержкой (debounce) по русским и альтернативным названиям.
  - Фильтры по жанрам, типу издания (японская манга, корейская манхва, китайская маньхуа) и возрастному рейтингу.
- **Светлая и тёмная тема:** удобное чтение в любое время суток.
- **Развертывание на любом статическом PHP-хостинге:**
  - Готовые `.htaccess` и `index.php` для роутинга в режиме SPA (без 404 ошибок при обновлении страницы на пути `/manga/...` или `/read/...`).
  - Опциональный встроенный прокси картинок и API в `index.php` на случай провайдерских ограничений.

## Запуск в разработке
```bash
# Установка зависимостей (уже выполнена)
npm install

# Запуск дев-сервера
npm run dev
# Сервер доступен по адресу: http://localhost:3000
```

## Сборка для продакшена (PHP хостинг / Open Server)
```bash
# Генерация статического SPA бандла
npm run generate
```

Сгенерированные файлы находятся в папке `.output/public`:
- `index.html`, `200.html`, `404.html`
- `_nuxt/` (стили и скрипты)
- `index.php` (маршрутизатор для PHP-хостингов и fallback)
- `.htaccess` (правила rewrite для Apache)

### Запуск в Open Server Panel
1. В корне домена `f:\OSPanel\domains\manga\www` уже находится скрипт `index.php`, который автоматически отдаёт актуальную сборку из `.output/public`.
2. Запустите Open Server и откройте `http://manga/` в браузере.

## Публикация на Vercel

Vercel не выполняет PHP, поэтому прокси ReManga для этого деплоя живёт в `server/api/remanga/[...path].ts`. Локальный Open Server по-прежнему использует `public/api/remanga.php` после `npm run generate`.

1. Залейте репозиторий на GitHub и импортируйте его на [vercel.com/new](https://vercel.com/new).
2. Framework Preset: **Nuxt.js**. Build Command оставьте `nuxt build` (скрипт `build`). Output Directory не задавайте — его соберёт Nitro.
3. Node.js: **22.x**.
4. Деплой. Маршруты `/manga/...` и `/read/...` открываются как SPA, запросы `/api/remanga/...` идут в serverless-функцию.

Картинки глав проксируются через ту же функцию. На Hobby у ответа есть лимит размера: очень тяжёлая страница может не открыться.
