# 🐱 N.ECOMANGA — Онлайн-читалка манги & Android-приложение

Современный, быстрый и адаптивный веб-сервис и нативное мобильное приложение для чтения манги, корейской манхвы и китайской маньхуа на русском языке.

---

## 📱 Скачать приложение для Android

Готовый установочный файл приложения автоматически собирается и публикуется в репозитории:

👉 **[Скачать последнюю версию NecoManga.apk](https://github.com/moorupmup/necomanga/releases/latest)**

1. Перейдите по ссылке выше в раздел **Releases** и скачайте файл **`NecoManga.apk`** в блоке **Assets**.

4. Приложение установлено и готово к чтению! 🎉

## ✨ Основные возможности

### 📱 Мобильная адаптация под смартфоны
- **Нижний таб-бар (Bottom Navigation):** Быстрый доступ в одно касание под большой палец: *Главная*, *Каталог*, *Закладки*, *История*.
- **Поддержка Safe Areas:** Корректные отступы под вырезы камер («челку») и нижнюю системную полосу жестов Android.
- **Сенсорные зоны в ридере:** В постраничном режиме экран разбит на 3 зоны: *Левые 30%* — назад, *Центр 40%* — меню/настройки, *Правые 30%* — вперед.
- **Мобильные шторки (Bottom Sheets):** Фильтры каталога и настройки читалки открываются плавными нижними шторками.
- **Плавающая кнопка «Продолжить чтение»:** Всплывает при скролле списка глав над нижним таб-баром.

### 📖 Читалка глав
- Два режима: непрерывная вертикальная **лента (Webtoon)** и **постраничный** просмотр.
- Настройка ширины холста (Стандарт, Широкий, На весь экран).
- Автоматическое запоминание последней прочитанной главы и прогресса.
- Поддержка горячих клавиш на ПК (`A` / `D`, стрелки `←` / `→`).

### 📚 Каталог и умный поиск
- Огромная база тайтлов через API ReManga на русском языке.
- Быстрые фильтры по типам: *Корейская манхва, Китайская маньхуа, Японская манга, Рукомикс*.
- Сортировка по популярности, рейтингу, обновлениям, просмотрам и новизне.
- Фильтрация по статусам (*Онгоинг / Завершён*) и десяткам жанров.
- Живой поиск с автодополнением по русским и альтернативным названиям.

### 🔖 Закладки и история чтения
- Локальное сохранение в `Pinia` + `localStorage` — регистрация не требуется.
- Категории закладок: *Читаю, В планах, Брошено, Любимое, Прочитано*.
- Раздел «Вы читали» с фиксацией времени и прогресса по главам.

## 🛡️ Архитектура обхода блокировок ReManga

1. **Защита от DDoS-Guard:** Серверы ReManga блокируют облачные дата-центры (Vercel, AWS, Beget и т.д.) кодом `403 Forbidden`. В мобильном приложении на базе **Capacitor** все запросы идут напрямую с мобильного IP-адреса пользователя, минуя блокировки.
2. **CapacitorHttp:** Плагин перехватывает сетевые запросы внутри WebView и выполняет их нативным сетевым стеком Android — без ограничений CORS.
3. **Обход анти-хотлинка картинок:** В читалке страницы загружаются с заголовком `Referer: https://remanga.org/` и конвертируются в локальные Blob URLs, гарантируя стабильную загрузку изображений с `img-reserve.reimg2.org`.

## 🛠️ Стек технологий

- **Фронтенд:** [Vue 3](https://vuejs.org/) (Composition API), [Nuxt 3](https://nuxt.com/) (SPA-режим)
- **Стилизация:** [Tailwind CSS](https://tailwindcss.com/), кастомные OKLCH градиенты, Glassmorphism
- **Стейт-менеджмент:** [Pinia](https://pinia.vuejs.org/) + VueUse LocalStorage
- **Иконки:** [Lucide Vue Next](https://lucide.dev/)
- **Мобильная платформа:** [Capacitor 8](https://capacitorjs.com/) (Android)
- **CI/CD:** [GitHub Actions](https://github.com/features/actions) (автосборка `.apk` на Ubuntu с Java JDK 21 и Android SDK)

## 💻 Локальная разработка

### Требования
- Node.js 22.x
- Open Server Panel (для локального PHP-прокси при веб-разработке)

### Запуск проекта
```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки Nuxt
npm run dev
# Доступен по адресу: http://localhost:3000
```

### Генерация статики и синхронизация с Android:
```bash
# Генерация SPA и синхронизация веб-бандла в android/app/src/main/assets/public
npm run cap:sync
```

### Запуск через Open Server Panel:
1. Скопируйте проект в папку домена Open Server (например, `domains/manga/www`).
2. В корне домена файл `index.php` и `public/api/remanga.php` обеспечивают роутинг и локальный прокси API.
3. Откройте `http://manga/` в браузере.

## ⚙️ Настройка GitHub Actions для автоматических релизов

Сборка настраивается автоматически через файл `.github/workflows/build-apk.yml`. При каждом `git push` в ветку `main` в облаке собирается свежий APK.

> [!IMPORTANT]
> **Если релиз не создался автоматически:**
> В GitHub по умолчанию права токена сборщика могут быть ограничены. Чтобы включить создание релизов:
> 1. Откройте репозиторий на GitHub → **Settings** (Настройки).
> 2. В левой колонке перейдите в **Actions** → **General**.
> 3. Внизу найдите блок **Workflow permissions** и выберите:
>    🔘 **Read and write permissions**
> 4. Отметьте галочку:
>    ☑️ **Allow GitHub Actions to create and approve pull requests**
> 5. Нажмите **Save**.
